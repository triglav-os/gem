The full sample session checks repeated Stout drags, Terminal movement and closure, framebuffer changes and independent RPC responsiveness. They check the global Locations command and directory chooser, compact Desk menus and File Open. Separate Trash scenarios exercise icon-view double-clicks, an upside-down-T XOR icon/title contour, live Trash-title inversion before button-up, file and non-empty-folder moves, plus cancel-default and confirmed Empty Trash in direct and proxy modes. They also force a failed move and immediately open another folder. The Trash unit test covers restore, collision handling, symlink-safe purge, same-volume store selection and cross-filesystem directory moves. The full sample session also opens Workspace through its exposed label while all applications are running. It holds the system menu open across a partial RPC frame and verifies that the Shutdown alert preserves all windows and client connections through a seven-second alert wait. All 34 demos run through Rasta in direct and proxy modes. UAT checks framebuffer references and scripted input; terminal cases verify a real shell command by reading its output file. The SDL viewer uses its dummy video driver unless UAT_SDL_DRIVER is set.

Passing these cases establishes the documented coverage, not every possible input or historical Atari device extension. See [transport scope](../architecture/API_TRANSPORT.md) and [demo scenarios](UAT.md).
